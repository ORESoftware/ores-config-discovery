# v0.2.2 promotion target

Tracking: #9.

The immutable `v0.2.2` tag must target the reviewed hardened code authority commit identified by the issue (`1ffd946…`), not a later documentation-only commit and not a moving branch.

Promotion evidence must verify the exact tag target, stepful CI on that source identity, and the published artifact/provenance produced from it. Do not fabricate a tag with a branch, hand-author package-lock/provenance data, or retarget an immutable release after publication.

This source change documents the gate only; tag creation and publication remain explicit release operations.
